## Source boundaries
Thin route composition in src/routes/app; feature UI under src/components/learning/{guides,outline,study,editor,blocks,assessments,portability,progress}; shared primitives remain src/components/ui; pure models, browse-query, typed registries, draft coordinator and scoped state under src/lib/learning; endpoint functions in src/lib/api/modules per API_ARCHITECTURE. Components never call raw fetch. Avoid generic CRUD/store framework and empty R2 directories. Cross-feature coding integration through existing API modules and explicit invalidation boundary, not imports of another feature's private component state.
## State ownership
URL owns selected guide/node, mode, library search/filter/sort/page; validate and canonicalize query, use replace for transient filter edits and push for meaningful navigation. Route-scoped async reads via Solid 2 createMemo/Loading/Errored or createProjection for keyed reconciliation; refresh/affects and action per installed APIs, independent dashboard boundaries. Server DTOs authoritative; no duplicate derived progress in writable store. Workspace owns outline expansion, selection/focus, tabs, transient dialogs; editor owns local draft, acknowledged revision, operation queue and conflicts; attempt workspace owns unsaved answers/flags, server deadline and authoritative revision. Auth-scoped bounded memory cache only if needed, key by epoch+resource+revision, clear on logout/switch, abort on disposal, ignore stale responses. No shared server singleton. Use two-function createEffect, props read not destructured, draft store setters, onSettled cleanup; no Solid1 createResource/onMount or React hooks. Test flush after writes. No optimistic completion/grade/structural changes until server ack; local draft editing immediate.
## Editor and assessments
Separate canonical typed AST from editor adapter and read-only renderer; exhaustive block registry, runtime decoding and safe unknown fallback. Evaluate editor engine with actual Solid2/SSR/IME/keyboard/paste/bundle/license spike before selection. Browser-only lazy mount and disposal, no editor in study chunk. Per-block serialized autosave, 600ms proposed debounce, coalesce latest draft, capture operation ID/revision/payload, stale ack updates acknowledged base only, explicit conflict compare/reapply, navigation guard when dirty, optional consent-based persistent recovery per security spec. Structural mutations serialized at workspace scope, reconcile authoritative tree; stable IDs preserve selection. Attempt timer derived from server deadline and clock offset, monotonic elapsed display, recheck on visibility/reconnect, never client-authoritative; explicit expiry finalization, no GET side effects. Flush answer queue before submit or atomic final batch, distinguish pending review/final result, no keys in active DTO. Avoid automatic retry of ambiguous mutation; receipt reconciliation.
