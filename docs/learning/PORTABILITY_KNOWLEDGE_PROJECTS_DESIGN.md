# Phase 1 — Portability, knowledge management and practical learning

Proposed UX specification; no application implementation. Existing LG-04/LG-08 and capability expansion remain the basis. Release tiers below are proposals pending consolidated review.

## Import and export
Release 1 Markdown and versioned JSON, reusable guide templates (ordinary guide copies). Release 2 CSV questions/cards, evaluate Anki interoperability, portable ZIP with attachments and PDF resources. Later sanitized HTML conversion. Do not promise lossless conversion from arbitrary formats. Import wizard: source, parse/validate, editable hierarchy preview, warnings/resolution, confirm, result. Markdown heading mapping explicit; preserve code fences, math, links, tables and parent content where supported. Unknown syntax must warn and preserve safe source where feasible. Preview and commit use same validated representation and revision; no silent overwrite or merge. Bound bytes, nodes, depth, decompression, file count and parsing time; reject traversal, unsafe URLs, scripts and archive bombs. No server fetching arbitrary URLs by default. Atomic creation or staged inaccessible import with cleanup; retry idempotently. Export distinguish readable Markdown from lossless supported JSON and later media bundle. Separate authored content from private personal records; explicit inclusion options, version manifest, stable reference mapping, missing attachment warnings, authorization and safe filenames. Test round trips, malformed inputs, interruption and cross-account isolation.

## Knowledge workspace (basic notes R1; advanced R2)
Global search across authorized guide titles, steps, text blocks, notes, resources, questions/cards and projects as available. Group results by type, highlight safely, filter guide/type/tag, navigate stable deep links. PostgreSQL full-text search and suitable indexes first; evaluate multilingual tokenization, no external search service by default. Notes private and independently editable; standalone notes, step-linked notes, bookmarks, highlights, tags and cross-guide links in R2. Explicit backlink relationships; stable IDs, broken-link recovery, no cross-account disclosure. Highlight anchors use block ID/revision plus quoted context; show stale anchor instead of silently relocating. Search and export honor deletion/archive and permissions. Autosave, conflict recovery and keyboard navigation. No graph visualization required for initial release.

## Practical learning
R1 checklist/self-attested activity and coding problem links; R2 project/assignment workspace with objective, instructions, deliverables, milestones, rubric, evidence text/link/private files, reflection and revisions. Standalone projects or linked to multiple steps through explicit activity references. Distinguish draft, submitted, self-reviewed and completed; do not imply external verification. Rubric criteria with optional points and explicit completion rules; immutable submitted evidence snapshots where needed, editable drafts. Required activity gates use authoritative completion; changing requirements preserves history and explains invalidation. Evidence uploads reuse revised private media lifecycle, quotas, safe MIME validation and authorized delivery. No arbitrary code execution, unsafe embeds or public evidence by default. Support nontechnical activities equally: language recordings, math proofs, hardware experiments, essays. R3 isolated execution only after threat model.

## Acceptance
Import nested Markdown with code headings inside fences; preview errors and cancel without partial guide; round-trip supported JSON; reject malicious archives and unsafe links; duplicate guide without personal records; search private notes across guides without leaking other accounts; moved step retains backlinks; deleted anchor visibly stale; recover interrupted note/evidence save; assignment submission retry idempotent; rubric revision preserves history; optional evidence does not silently change completion. Responsive 360/768/1440, 200% zoom, keyboard, screen reader, light/dark. Follow repository conventions and generated API contracts.

## Phase 2 decisions
Portable schema and media manifest, exact Markdown mapping, import limits, search indexing/language strategy, link and highlight anchor semantics, assignment/evidence revision and retention, rubric scoring and storage quotas. No runtime tests executed.
